# Student Registration Form

A simple Student Registration Form created using HTML5 as part of my web development learning journey.

## About the Project

This project demonstrates how to create a basic registration form using HTML form elements and display student information in a table.

## Features

- Full Name input
- Email input
- Password input
- Gender selection using radio buttons
- Skills selection using checkboxes
- Date of Birth input
- Register button
- Submitted Students table with dummy data

## Technologies Used

- HTML5

## HTML Concepts Practised

- Forms
- Input types
- Labels
- Radio buttons
- Checkboxes
- Buttons
- Tables

## Project Purpose

This project was created to strengthen my understanding of HTML forms, input elements, tables, and basic webpage structure.
